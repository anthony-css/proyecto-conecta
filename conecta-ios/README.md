# CONECTA iOS

El proyecto Xcode se incorporará cuando se defina la referencia de la app. La integración usará Firebase Authentication para los participantes y enviará el ID token a la API de CONECTA.

Al crear la app, registra su Bundle ID en el mismo proyecto Firebase que usa Spring, agrega el SDK y el archivo de configuración iOS, y verifica el acceso con el simulador en una Mac. La cuenta de servicio de Spring se configura exclusivamente en el backend.
